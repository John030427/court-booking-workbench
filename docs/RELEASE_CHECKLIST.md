# 公开发布前检查

当前状态：仅文档准备，不是软件发行版。

## 仓库与权限

- [ ] 旧仓库保持私有，不复制旧 Git 历史、内部交接资料、Issues 或日志。
- [ ] 新仓库只导入审核后的白名单文件，初始仅保留 main；不删除旧仓库分支。
- [ ] 核实代码来源、分发授权、第三方许可证与必要署名，不用删署名的方式隐藏来源。
- [ ] 核实新提交的作者信息、提交说明、文件元数据与公开范围。
- [ ] 使用者核对最终发布清单后，再公开；说明公开内容可能被缓存、转载，不能保证匿名。

## 功能与隐私

- [ ] 平台域名、场馆配置、显示名称、应用标识和安装路径的通用化方案已实现并测试。
- [ ] 未配置平台时明确停止，不请求旧平台，也不宣传支持任意预约网站。
- [ ] 配置脚本、提示词、安装包入口及撤销流程与新版本一致。
- [ ] 无真实登录信息、个人联系方式、订单记录、原始网络包、证书私钥或备份文件。
- [ ] 检查文本、二进制素材、截图、旁白、字幕及 Git 元数据，而不只检查 README。
- [ ] 离线测试与 JavaScript 语法检查通过，没有使用真实订单做发布测试。

## 安装包

- [ ] 生成干净 ZIP 和安装程序，扫描包内全部文件，生成 SHA-256 清单。
- [ ] 在干净 Windows 环境验证中文路径、启动、重复启动、退出、升级和卸载。
- [ ] 不覆盖现有数据，不清空未确认订单，不干预别的进程或全局网络。
- [ ] 首次启动的真实预约/测试模式提示准确，用户可理解后自主选择。

## 视频和 README

- [ ] 获取完整 MP4，或从审核后的工程重新渲染；短素材不能充当完整教程。
- [ ] 视频、音轨、字幕、章节、封面和元数据均通过隐私检查。
- [ ] 新持续监控功能、按钮和提示与发布版本一致；模拟画面有清晰标识。
- [ ] Releases 上传实际安装包、完整视频、字幕和校验文件后，填写有效下载链接。
- [ ] 从未接触项目的新手角度走完 README，删除准备中提示前确认每一步真实可用。
