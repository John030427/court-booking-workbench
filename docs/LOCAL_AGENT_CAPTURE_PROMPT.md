# 给本地 AI 的配置提示词

在要使用工作台的 Windows 电脑上交给有本机终端权限的 AI。网页版聊天不会自动获得本机文件和窗口权限。敏感信息只保存在本机配置，不要粘贴给 AI。

这份提示词用于检查和安全接入，不代表通用化脚本已经发布。遇到适配缺失应停止，不猜测接口。

---

请帮助我检查并配置场地预约工作台的账号接入。用中文沟通，先只读检查，不立即修改系统。

## 我的环境

- 操作系统：Windows 10/11，具体版本请检查。
- 工作台目录：请让我选择，不要扫描整台电脑寻找账号资料。
- 安装方式：安装包 / ZIP / 源码 / 不知道。
- 代理客户端：由我说明；不清楚时只读检查常见客户端进程。
- 接入方式偏好：优先不修改网络；需要采集方案时先解释再确认。
- 预约站点：从我指定的官方页面确认，仅在本机使用，不公开。

## 必须遵守

1. 每次写操作前说明修改内容、影响范围、备份和撤销方式，等我回复「可以」。
2. 不输出 Token、Cookie、身份编号、手机号、代理控制密钥或任何凭证预览；不上传原始请求和日志。
3. 不调用下单接口，不创建、停止或修改抢场/监控任务，不清空未确认订单，不更改测试模式。
4. 不擅自切换代理模式、TUN、系统代理，不更改订阅、节点、DNS、防火墙或系统执行策略。
5. 只处理本工具明确需要的单个预约站点，不扩大采集到其他站点或整个浏览器。
6. 端口被其他程序占用就报告；不结束其他程序、代理客户端或官方登录客户端。
7. 安装证书需我确认，只使用本机生成的证书并限于当前用户；不上传私钥，不关闭证书校验。
8. 环境策略拦截操作时停下，不换方式绕过。不要承诺匿名、永久免费登录或一定预约成功。

## 第一步：只读核实

- 检查工作台版本和实际程序路径、8766/8080 监听进程、运行中任务。
- 状态 API 只提取安全字段；不要打印完整配置或完整 JSON。
- 读取当前版本接入文档、适配代码、配置脚本和撤销流程，确认平台及代理客户端是否支持。
- 识别代理客户端与分流模式、目标域名的现有规则，以及采集出口是否可能回环。
- 不打开无关账号文件，不遍历其他浏览器资料，不读取未授权流量。

输出简短检查表，分别列出已确认、未确认、阻塞项。若代码仍硬编码其他平台或没有对应适配，先解释，不要仅替换域名后宣称兼容。

## 第二步：提出方案，等我确认

优先考虑页面脚本；自动采集需要本机代理与证书时说明具体影响。给出精确修改清单和备份方案，保证可撤销且不会影响其他流量。

修改必须适应当前客户端配置格式，保留其他规则。不知道如何放置规则、证书归属不明、存在活动任务时，停止并询问。

## 第三步：执行获准的配置

只修改批准范围。需要我重新打开官方客户端或登录时明确提醒，不代替我处理身份验证。检查日志时脱敏并控制范围，不导出原始鉴权报文。

## 第四步：验证与交接

- 分别检查连接、登录信息同步和平台验证，不把三者混为一谈。
- 向平台发只读验证请求前再次确认；不通过真实预约验证配置。
- 自动恢复测试单独征得同意，不在放号窗口或活动任务期间触发刷新。
- 告诉我实际改了什么、是否测试成功、尚有哪些限制，以及准确的撤销步骤。
